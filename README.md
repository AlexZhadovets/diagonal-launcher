# Діагональ — лаунчер для Android

Кожна програма на робочому столі — кольорова діагональна смуга (колір береться з іконки).

- **Тап** по смузі — запуск програми.
- **Свайп по діагоналі** (зліва-згори ↔ справа-знизу) — гортання всіх смуг, з інерцією.
- **Довге натискання + тягнути** — переставити програму; порядок зберігається. Біля краю екрана список сам прокручується.
- **Кнопка ↩** (внизу праворуч) — відкриває налаштування «Головний екран», де можна повернути стандартний робочий стіл.
- **Home**, коли лаунчер уже відкритий, — повернення до початку списку.

## Як отримати APK

1. Завантаж цю папку в новий репозиторій на GitHub (або дай Claude запушити).
2. GitHub Actions сам збере APK (~5 хв). Вкладка **Releases** → `diagonal-launcher.apk`.
3. Відкрий посилання на телефоні, скачай, дозволь «Встановлення з невідомих джерел» для браузера, встанови.
4. Натисни Home → обери «Діагональ» → «Завжди».

Вручну: `gradle assembleRelease` (потрібні JDK 17 і Android SDK) → `app/build/outputs/apk/release/app-release.apk`.

> APK підписується ключем `app/signing.jks`, що лежить у репозиторії, тому нові збірки встановлюються поверх старих. Ключ публічний: він годиться лише для особистого використання, не для Google Play.
